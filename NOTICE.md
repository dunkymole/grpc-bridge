# Third-party acknowledgements

The bridge uses only Go's standard library. Its distribution includes the Go
runtime and a CA certificate bundle from the build image.

The browser uses these separately licensed components:

- h2ts 0.1.2, Debdatta Basu — used under MIT (upstream offers MIT OR Apache-2.0).
  [Source](https://github.com/debdattabasu/h2ts). Provides HTTP/2 and HPACK;
  Vendored at commit `3c51e07bf0035c3228af8c72a58072d778cae395` in `web/src/h2`.
  Local adaptations expose retry evidence, response commitment, and GOAWAY
  draining, and improve cancellation/admission cleanup. See its README for details.
- `@connectrpc/connect` 2.2.0 — Apache-2.0.
  [Source](https://github.com/connectrpc/connect-es).
- `@bufbuild/protobuf` 2.15.0 — Apache-2.0.
  [Source](https://github.com/bufbuild/protobuf-es).

Python uses grpcio, grpcio-tools, and protobuf under their respective upstream
licenses. Package source and license files remain in installed distributions.
Development tools are listed in `web/package.json` and are not runtime
dependencies of the bridge. Bundled browser license notices are generated by
the web build and copied into the scratch image.

The `@dunkymole/grpc-bridge` package is MIT licensed and declares the browser
Connect and Protobuf as npm dependencies and includes the adapted h2ts engine.
Its tarball includes this project's license
and the bundled third-party notice files.
